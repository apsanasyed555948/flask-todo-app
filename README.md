# Flask To-Do List

## Objective

The objective of this project is to build a simple web application using Flask and demonstrate basic backend fundamentals.

## Requirements Covered

- Flask routing
- HTML templates
- GET and POST form handling
- Basic data storage
- Adding and deleting tasks
- Bootstrap UI

## Technologies Used

- Python
- Flask
- HTML
- Bootstrap

## Features

### Add Task

Users can enter a task using an HTML form. The form sends the data to the Flask backend using a POST request.

### Display Tasks

The Flask application passes the task list to the HTML template and displays the tasks.

### Delete Task

Users can delete tasks using the delete button.

### Bootstrap UI

Bootstrap is used to create a clean and responsive interface.
